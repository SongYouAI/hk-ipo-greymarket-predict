# 港股打新预测 · 模型方法与因子算法（Agent 备查）

> 本文件是 `hk-ipo-greymarket-predict` skill 的算法底稿。报告里已含因子总表，本文件给 agent 讲清"每个数字怎么算出来的"，便于回答老板"为什么是这个数"。

## 0. 三个价格（铁律，别混）

| 价格 | 形成 | 本模型 |
|---|---|---|
| 暗盘开盘价 | T-1 17:00 第一笔 | **不建模**（各券商不互通、情绪化）→ 仅给"情绪初判" |
| 暗盘收盘价 | T-1 21:30 | **S2 预测目标**（主输出） |
| 首日开盘价 | T 日 9:30 | **S3 预测目标**（暗盘已出才有值） |

## 1. 数据管线

1. `api_get('/ipo-stocks')`：HMAC-SHA256 签名（SECRET 内置）拉全部新股。
2. `fetch_gtimg`：腾讯 `qt.gtimg.cn` 拉恒指涨跌 + A 股现价（算 A+H 折价）。返回 GBK，数值字段为 ASCII 可直接取。
3. `extras.json`：内置 117 只因子库（保荐人战绩 / 首日开盘 / 基石 / 绿鞋）。

## 2. 动态分桶（S2 核心，每次实时重算）

- 样本 = 近 12 个月、有超购且有暗盘实测的新股（当前 n≈106）。
- 超购分 7 档：`[0,15,100,500,1000,3000,6000,∞]`。
- 每档取：**中枢 = 中位数**；**区间 = [P25,P75]**（不对称，吃右偏）。
- 实证复算与插件静态桶几乎一致（各档中位数 ±0.1），说明重算稳定。
- **降级**：无超购 → 有 A+H 走 `ah_implied`、否则中性兜底（中枢≈0、宽区间）。

## 3. 各因子算法

| 因子 | 算法 | 参与阶段 |
|---|---|---|
| 超购分档 | 取所属档中位数 + [P25,P75] | S2（主导） |
| A+H 折价锚 | `clamp(0.238 × 溢价%, ±12)`（统一斜率；原两处口径已合并） | S1/S2 |
| 残差分层修正 | 超购档外的边际信息：保荐人/基石/国配/赛道/规模 各取"档位残差均值"求和，截断 ±10（仅超购存在时启用，避免与桶重复计价） | S2 |
| 情绪周期平移 | 近12月 破发率/中位暗盘涨幅 判冷热市：冷市 −8 / 热市 +3 / 中性 0，整体平移中枢 | S1/S2/S3 |
| 大盘环境 | 恒指 ×0.3（S2）/ ×0.4（S3），实时 | S2/S3 |
| 国配超购 | >5倍 +2（S3直接参与；S2经残差分层间接计入） | S3 |
| 发行规模 | 募资额分档（<30亿 / 30–300亿 / >300亿），取**该档样本残差均值**（非固定加减分） | S2 残差分层 |
| 保荐人战绩 | `(历史首日均值 − 市场基准) × 权重`，**S1 15%±8、S3 20%±10**；S2 经残差分层间接计入 | S1/S3 |
| 基石配售 | `(占比 − 35%) × 0.12`，±6pt（招股章程实读） | S1/S3（S2 经残差分层间接计入） |
| 妖股标定 | 暗盘>50% → `暗盘 × ratio`，ratio = 样本实测(首日开盘/暗盘收盘)中位比 ≈ **1.01**（原 0.7 已证伪） | S3 |

## 4. 置信与区间语义

- 置信星级由**区间宽度**定：≤10pt→★★★，≤25pt→★★，否则★。
- 区间 = 真实 50% 中央区间（名义覆盖率），越宽 = 这只越没规律。
- **永不承诺点位**，只给方向+区间。

## 5. 已实测证伪的旧规则（重要）

- ❌ "妖股首日开盘 = 暗盘 × 0.7"（旧插件拍脑袋）→ ✅ 样本实证 ≈1.01。
- ❌ "S2 把 6 个因子全砍最好"（消融结论偏脆，因桶已内化均值）→ ✅ 改为残差分层边际修正。
- ❌ "FLAT 兜底中位 +29.7%"（右偏误导）→ ✅ 中性≈0 宽区间。
