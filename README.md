# 港股打新 · 暗盘/首日开盘预测 + 中签后的持仓处置单

> 输入一只中签港股的名称或代码，输出两样东西：
> ① **带区间、带置信、带逐项计算过程**的暗盘收盘价预测（S2，主）与首日开盘价预测（S3，暗盘发生后）；
> ② 一份 **「中签之后怎么操作」的处置单**——不需要你回答任何问题，现金/融资两套、七档落点动作、盘中形态纪律一次给全。

纯 Python 标准库，**零第三方依赖**，运行时实时联网取数。预测中枢走**近端优先的分层窗口**（近3月 → 近6月 → 近12月），所以不同时段问同一个代码，会得到随市况刷新的评估。

## 一、它做什么（先把边界说清）

### 1. 预测的三个价格口径

港股打新有三个价格，各券商不互通，很多"预测"就混在这里。本模型只对能建模的动手：

| 价格 | 出现时间 | 本模型的态度 |
|---|---|---|
| 暗盘**开盘**价 | T-1 16:15 第一笔 | **不建模**。开盘几分钟易被大单砸偏、各券商独立撮合 → 只给「情绪初判」（±5~15pt 情绪带，明确标注非模型输出） |
| 暗盘**收盘**价 | T-1 18:30 | **主预测目标（S2）** —— 信息最全、口径最统一 |
| **首日开盘**价 | T 日 9:30 | **S3 目标** —— 仅当暗盘已发生（有暗盘收盘实测）才有值 |

### 2. 处置单回答的问题

| 你可能会问 | 报告里的答案在 |
|---|---|
| 暗盘破发了，要不要熬到首日？ | 三条总纲 + 七档卖出表（破发档：**直接清，别等**） |
| 暗盘涨很多，是不是该直接卖？ | 七档表按落点给动作（+50%~+100% → 分批；>+200% → 大比例落袋） |
| 用绿鞋托底，第二天卖给绿鞋行不行？ | 绿鞋纠偏（**托价上限＝发行价，机制上不成立**） |
| 暗盘低吸两手摊低成本？ | 现金/融资两栏第⑤条 + 摩擦成本 KPI（**一买一卖 1~2%，统计优势被吃光**） |
| 我是融资打的，做法一样吗？ | 融资栏：**提前一档执行**（利息按日计、不中签也付） |
| 暗盘会高开低走还是低开高走？ | 盘中形态纪律 + **诚实说明：站点无分时数据，无法预测，只给执行规则** |

**诚实边界**：只承诺「方向 + 区间」，不承诺点位。区间越宽 = 这只股在历史样本里越没规律，如实告知，好过假装精确。

## 三、持仓处置单（本项目的重点）

设计原则：**报告直接给解决方案，不追问用户中了几手、是否融资**；每份报告结构完全一致；每个判断都写清"为什么"和"样本量"。

| 区块 | 内容 |
|---|---|
| KPI 四卡 | 一手本金 / 该档暗盘破发概率 / 绿鞋 / 一买一卖摩擦成本 |
| 模型预期 | S2 区间 + 它对应哪个卖出档（**明确写"供参考，不是动作依据"**） |
| 一、三条总纲 | 破发→清 / 小赚→落袋 / 大赚→分批 |
| 二、七档卖出表 | 档位 / 动作 / 实测依据 / 为什么 |
| 三、盘中形态 | 15 分钟观察窗 / 高开低走 / 低开高走 / 缩量横盘 / **数据边界** |
| **破发豁免判定框** | 这只股破发到底「清仓」还是「留半仓」——按 A 股锚 × 破发深度给**唯一结论** + 依据 + 动作 + 边界 |
| **保荐人警示块**（嵌在豁免框内，琥珀金） | 本股保荐人在「温和破发 + 绿鞋」区间有未托价记录 → **一票否决，覆盖 A+H 豁免** |
| 四、三个误区 | 绿鞋≠发行价保证 / 摊低成本是心理账户 / 挂低价不改变成交价（每条带实测数字） |
| 五、现金 vs 融资 | 两栏各 5~6 条，含金额化的成本与"提前一档执行"原则 |
| 六、退出时点 | 首日开盘早段 ＞ 暗盘 ＞ 首日收盘 |
| 绿鞋纠偏 | 托价上限＝发行价；2026 年不少 A+H 为「首日入通」主动放弃绿鞋 |
| 实况回测 | 最近 ≥12 只已上市新股的滚动回放（含逐行明细） |
| 合规提示 | 融资利息 / 中签费 1.0085% / 券商独立报价 / 港股通不可参与 / 个税 |

### 为什么动作按「落点」分档，而不是按「预测」分档？

因为**动作必须在暗盘 16:15–18:30 两个小时内当场做**，那时只有实际成交价是确定的。预测只用来设预期。

### 核心实证依据

口径：近 12 个月已上市新股，**剔除 `openPct` 缺失样本**后 n=94。
核心指标 = 「首日开盘涨幅 − 暗盘涨幅」，**> 0 表示"熬到首日开盘再卖"好过"暗盘直接卖"**。

| 暗盘落点 | n | 熬首日更优 | 中位差 | 结论 |
|---|---|---|---|---|
| ≤ −10% | 6 | 2/6 | −3.3pt | 清仓（尾部极厚，见过 −3.5% 熬成 −33.9%） |
| −10% ~ 0 | 6 | 3/6 | −1.9pt | 清仓，别等绿鞋（**破发组合计 12 只：5/12 更优、翻红 0/12**） |
| 0 ~ +20% | 22 | 5/22（23%） | −1.8pt | 暗盘卖出为主（全样本最差档） |
| +20% ~ +50% | 19 | 7/19（37%） | −2.8pt | 落袋 6~7 成 |
| +50% ~ +100% | 23 | 14/23（61%） | +1.6pt | 分批（方差大，锁住两端） |
| +100% ~ +200% | 11 | 5/11（45%） | −1.4pt | 落袋 6~7 成 |
| > +200% | 7 | 4/7（57%） | +9.0pt，**P25 −15.0 / 最差 −24.8** | 大比例落袋，余量移动止盈 |

> 各档 n 合计 = 94 = 干净样本总数（每档只统计落在该档的样本；「破发组」12 只是 ≤−10% 与 −10%~0 两档之和）。

其他被采纳的实证结论：

- **摩擦成本**：一买一卖 ≈ 印花税 0.1%×2 + 佣金 + 平台费 15×2 + 结算费 ≈ **1~2%**。低价股受固定平台费影响更大（一手 2,160 HKD 时打平需 **1.7%**）→ **低吸倒手不划算**。
- **退出时点**：首日 **60% 高开低走**，收盘比开盘中位低 **4.5pt**；开盘 >+20% 的一组回落中位 **−6.3pt** → 越晚卖越吃亏。
- **一手本金**中位 4,377 HKD（最便宜约 1,000、最贵 2 万+，如 罗博特科 436×50 = 21,800）。

### 破发之后：什么情况下可以「留半仓等首日」（破发豁免判定）

最常见的实战问题是：「暗盘破发了，但第二天有绿鞋，能不能熬一熬等它按发行价开？」

把 12 只破发样本逐只拆开看，答案**不是看有没有绿鞋**：

| 破发情形 | n | 首日开盘回到发行价附近 | 开盘中位 − 暗盘中位 |
|---|---|---|---|
| **A+H + 温和破发（−5%~0）** | 3 | **3/3** | **0.0pt**（立讯精密 / 安克创新 / 中际旭创） |
| A+H + 深破发（≤−5%） | 3 | 0/3 | −18.7pt（滨化股份 / 普源精电 / 鼎泰高科） |
| 非 A+H + 温和破发 | 2 | 0/2 | −25.3pt（江西生物 / 龙丰集团） |
| 非 A+H + 深破发 | 4 | 0/4 | −26.0pt |

**关键反例**：江西生物、龙丰集团**都有绿鞋**、暗盘也只小跌（−3.5% / −1.5%），首日开盘却崩到 **−33.9% / −16.6%**。整体看，**破发 + 有绿鞋的 9 只里只有 3 只**回到发行价附近。

所以判别变量是 **「有没有 A 股价格锚（A+H）× 破发是否温和」**，不是绿鞋。豁免条件很窄：**只在 −5%~0% 且是 A+H 时成立，样本仅 3 只**——报告里会给这只股算一次判定，并同时写出边界（跌更深时同类 0/3），不把 3 只样本包装成规律。

判定本身是**三态**，由这只股**实际暗盘跌幅**决定（不是只看「是不是 A+H」）：

| 结论 | 触发条件 | 报告给的动作 |
|---|---|---|
| ✅ 适用 | A+H **且**暗盘落在 −5%~0% | 暗盘只卖一半，余量留首日开盘早段（9:30–10:00） |
| ◐ 条件性适用 | A+H，但暗盘还没出（仍在招股期） | 先记住规则，暗盘出来对号入座；跌破 −5% 自动失效 |
| ✗ 不适用 | 非 A+H，**或** A+H 但已深破发 | 破发直接全清，不等首日、不等绿鞋 |

注意最后一行里的第二种情况：**滨化股份（06745）就是 A+H，但暗盘 −21.3%**。光看「它是 A+H」就放宽成「可留半仓」是错的——A 股锚只在**温和破发**时救得回来。

### 再加一道闸：保荐人「不托价」记录（一票否决）

绿鞋托不托，最终是**人**在做。所以除了看「有没有 A 股锚」，还要看**谁在操盘**。

验证方法的关键是**选对比较区间**：只看「**温和破发（−5%~0）+ 有绿鞋**」——这是绿鞋**最该生效**的区间（只需托回 5% 以内）。深度破发时谁都托不住，那是**难度**问题；只有在"只需托一点点"时仍然失败，才指向操盘方**本身不托价**（态度问题）。用这个区间做对照，等于自动控制了「托价难度」。

实测（数据完整样本 n=5）：

| 保荐人 | 该区间项目数 | 未托回 | 明细 |
|---|---|---|---|
| **海通國際資本有限公司** | 2 | **2**（100%） | 江西生物 −3.5%→**−33.9%**、龙丰集团 −1.5%→**−16.6%** |
| 其余全部（中金 / 摩根士丹利 / 高盛 / 中信 / 摩根大通 / 广发…） | 3 | **0** | 中际旭创 +0.2pt、安克创新 +3.8pt、立讯精密 +4.9pt |

命中即**一票否决，覆盖 A+H 豁免**。两个必须说清的地方：

- **统计上不显著，仍设为否决**：该保荐人样本仅 2 只，Fisher 双侧 **p≈0.10**。理由是**风险极不对称**——走豁免的收益上限只是把 −4% 变成 0%（≈4pt），失败下限却是 **−30pt**。宁可错杀。报告里会把 p 值和样本量**原样写出来**。
- **门槛参数化、名单实时生成、不硬编码机构名**：`n≥2 且 失败≥2 且 失败率≥50%` 三条同时满足才进名单，每次运行从实测数据重算——数据一变名单自动变，也不会把某个机构名字写死成指控。

### 三个最容易亏钱的想当然（报告里逐条用数据回答）

| 常见想法 | 实测结论 |
|---|---|
| 「有绿鞋的项目，首日就会按发行价开」 | 不成立（3/9）。稳价人买在**首日连续交易时段**，而开盘价由**竞价**撮合——大卖压下照样低开 |
| 「暗盘低价捞货摊低成本，首日就能赚一点」 | 摊低成本是**心理账户**：总盈亏 = (O−P0) + (O−D)，捞货不改变原仓那部分，只新增一笔 (O−D) 的独立交易，还要扣 0.25~0.30% + 约 30 港元摩擦 |
| 「开盘前挂一个比开盘价低的价格直接出」 | **不改变成交价**：开盘竞价同一时段统一撮合，挂低价仍按开盘价成交（但在连续交易时段挂低价就会真的卖低） |

### 关于"要不要卖给绿鞋"——一个必须纠正的误解

绿鞋（超额配售权）的稳价人**只在跌破发行价时才买**，且**买入价不得高于发行价**（HKEX 上市规则 9.23），规模 ≤ 发行量 **15%**，窗口 ≤ 上市日起 **30 个日历日**。

所以散户**不可能"第二天卖给绿鞋赚一笔"**——托价上限就是发行价。真实可做的是：破发时**借稳价人的买盘把货出掉，代价是不高于发行价**。另外 2026 年不少 A+H 股为「首日入通」**主动放弃绿鞋**（全库 117 只中 82 只有，约 70%），所以建议的第一步永远是先确认这只有没有。

## 四、三阶段预测与详细计算过程

三个阶段按**时间相位**依次解锁（不是按数据有没有就随便标）：

```
招股截止前 ────────→ S1 招股期      方向性宽区间（无超购数据）
招股截止后→暗盘前 ──→ S2 中签后      暗盘收盘价预测（核心）
暗盘结束后 ────────→ S3 暗盘后      首日开盘价预测
```

### S1 · 招股期预测（信息最少，只给方向）

招股期还没有超购数据，缺了最重要的参考，所以只给**方向性宽区间**，不硬给点位。

**分支 A — A+H 股（有 A 股上市）**

```
中枢 = clamp(0.238 × A股较发行价溢价%, ±12)
区间 = [中枢 − 10, 中枢 + 10]，下沿不低于 −5
```

> A 股现价换算成港币后，相对港股发行价贵得越多，说明港股这边相对"便宜"，上市后向 A 股靠拢的动力越足。斜率 0.238 是回归标定值（取自 38 只样本）。注意：**折价深 ≠ 不会破发**，只是平均而言更暖，尾部照样有破发的。
> 口径提醒：标定必须用**招股截止日前的 A 股收盘价**，别用现价。

**分支 B — 非 A+H：赛道选档给宽区间**

按股票名称关键词推断赛道系数（站点没有行业字段，只能名称推断，报告里明确标注）：

| 名称命中关键词 | 赛道系数 |
|---|---|
| 科技/电子/半导体/芯片/智能/机器人/精密/光电/光伏/新能源/储能/电池/新材料/医药/生物/医疗… | +8 |
| 消费/食品/饮料/零售/品牌/传媒/文娱/旅游/宠 | +5 |
| 金/矿/资源/铜/锂/钢铁/化工/能源/电力/环保 | −5 |
| 证券/保险/银行/金融 | −2 |
| 未命中 | 0 |

```
系数 > 0  → 区间 [0, +18]
系数 < 0  → 区间 [−15, +5]
系数 = 0  → 区间 [−10, +20]
```

**再叠加两项（两分支共用）**

```
18C 特专科技章节               → 上沿 +5pt（合并单次计入，避免三重计价）
保荐人战绩 = (保荐人首日涨幅中位数 − 全库中位基准) × 0.15, clamp(±8)
基石配售   = (基石占比% − 35%) × 0.12,                    clamp(±6)
```

### S2 · 中签后预测（暗盘收盘价，核心）

配售结果公布后，超购倍数到手，这是信息最全的一刻。

**第 1 步 — 超购分档基准（近端优先分层窗口）**

超购分 7 档：

```
档边界 = [0, 15, 100, 500, 1000, 3000, 6000, ∞)   （倍）
中枢   = median(该档样本的暗盘涨幅%)
区间   = [中枢 − dLo, 中枢 + dHi]
         其中 dLo = 中枢 − P25，dHi = P75 − 中枢    ← 不对称，吃右偏尾巴
```

样本**逐档分层取**，每档取第一个满足门槛的窗口：

```
近3月（≥5 只）→ 近6月（≥3 只）→ 近12月（≥3 只）
```

> **为什么不用单一固定窗口？** 港股打新情绪一个月就能翻脸——实测 2026-05 暗盘中位 **+75.6%**，到 2026-09 已是 **−0.7%**。用 12 个月窗口会把"近期破发率 71%"稀释成"20.8%"。
>
> 严格因果 walk-forward 回测（预测第 i 只时只用它上市前的数据，n=66）：

| 方案 | MAE | 最近 12 只 MAE | 覆盖率 |
|---|---|---|---|
| 固定 6 月窗口 | 52.66 | 21.33 | 56/66 |
| **近3月→6月→12月 分层** | **46.56** | **18.49** | **63/66** |

> **为什么用中位数和分位、而不是均值和标准差？** 暗盘涨幅**右偏极严重**（妖股动辄 +100%），均值被右尾拉高，会给出系统性偏高的中枢；用 [P25, P75] 分位区间则天然收敛，且区间宽度有明确含义——它是**真实的 50% 中央区间**（标称覆盖率）。

**第 2 步 — 残差分层修正（替代"因子全砍"）**

超购档已经把"热度"吃进去了。还有边际信息的，是**同一热度档内部**的差异：

```
对每个因子取「档位」：
  保荐人：战绩偏离基准 >+3 → pos / <−3 → neg / 其余 mid
  基石  ：占比 >50% → high / <20% → low / 其余 mid
  国配  ：>5倍 → pos / <1倍 → neg / 其余 mid
  赛道  ：系数 >0 → pos / <0 → neg / 其余 mid
  规模  ：募资 <30亿 → pos / >300亿 → neg / 其余 mid

corr = Σ 各因子档位的「样本残差均值」(残差 = 该样本暗盘% − 它所属档中位数)
       每档至少 5 个样本才计入，方向互抵或样本不足则该项不修
corr = clamp(corr, ±10)
中枢 += corr
```

> 为什么是"残差"而不是直接乘权重？因为档中位数里**已经含了均值信息**，再按原始值加权就是重复计价。取残差只保留"同档内部的边际差异"，这才是真增量。

**第 3 步 — 大盘环境**

```
中枢 += 0.3 × 恒指当日涨跌%
```

**第 4 步 — 收敛**

```
中枢 = clamp(中枢, −40%, +400%)
区间 = [中枢 − dLo, 中枢 + dHi]（沿用该档分位半距）
```

**降级路径（超购未录时，绝不给假精确）**

```
有 A+H  → 中枢 = clamp(0.238 × A股溢价%, ±12)，半宽 10/12pt，标「预估」
无 A+H  → 中枢 = 0，半宽 18/22pt（中性兜底，明说"这只我算不准"）
```

> 历史上这里曾是「FLAT 兜底取中位数 +29.7%」——那是右偏样本的误导性数字，已废弃。

**⚠ 已删除：固定的「冷热市平移」**

旧版按「破发率 >50% 或中位暗盘 <0 → 冷市 −8pt；破发率 <30% 且中位暗盘 >10% → 热市 +3pt」整体平移中枢。已删除，依据：

| 方案（严格因果 n=46） | MAE | 中位偏差 | 方向命中 |
|---|---|---|---|
| 桶中位 **+ 固定平移** | 40.05 | −8.4 | 37/46 |
| **桶中位（无平移）** | **39.4** | **−5.4** | **38/46** |
| + 情绪动量项（追最近 30 天） | 41.8~42.9 | −19.5 | 33/46 ✗ |
| + 滚动偏差校正 | 41.2 | −1.2 | 32/46 ✗ |

即那个固定平移是**负贡献**（尤其它会把已转冷的市场仍判为"热市＋3pt"）。而"追最近情绪"是典型追高，实测更差。**正确的"用最新数据"方式是缩短窗口（分层），不是加动量项。**
情绪不靠拍脑袋的加减项，而是靠 ① 分层窗口自动吸收，② 「近 30/90 天」指标如实呈现给决策者（且标签与数字**同窗口**，不混口径）。

### S3 · 暗盘后预测（首日开盘价）

暗盘已收盘，锚点变成实测：

```
暗盘 > +50%   → 中枢 = 暗盘% × ratio，ratio = 样本实测「首日开盘 / 暗盘收盘」中位比，区间半宽 18pt
暗盘 < −5%    → 中枢 = 暗盘% − 2（破发延续），半宽 10pt
其余           → 中枢 = 暗盘%（不调整），半宽 10pt

再加：
  隔夜大盘  → += 0.4 × 恒指涨跌%
  国配 > 5倍 → += 2pt
  保荐人战绩 → (保荐人首日涨幅中位数 − 全库中位基准) × 0.20, clamp(±10)   ← 首日口径
  基石配售   → (基石占比% − 35%) × 0.12,                        clamp(±6)
中枢 = clamp(中枢, −45%, +400%)
```

其中 `ratio` 由引擎**每次运行现算**：取所有「暗盘 > 50% 且有首日开盘实测」的样本，`median(首日开盘% / 暗盘收盘%)`，再 `clamp(0.7, 1.3)`，样本不足 5 个退化为 0.7。

> 原插件写死 0.7（"暴跌妖股首日大幅回落"的拍脑袋规则）。41 只样本实测中位比 ≈ **1.01** —— 妖股首日开盘**并未系统性收窄**，只是波动放大。已按样本标定。

### 暗盘开盘价 · 情绪初判（辅输出）

```
mid  = (S2 区间上沿 + 下沿) / 2
band = 15pt（S2 中枢 > 50%）/ 8pt（S2 上沿 < 0）/ 5pt（其余）
初判区间 = [mid − band, mid + band]
```

明确标注「非模型输出」：开盘前几分钟大单博弈主导，不可建模。

## 六、动态校准：为什么每次运行结果会变

| 机制 | 做法 | 效果 |
|---|---|---|
| **分层滚动窗口** | 逐档取 近3月(≥5) → 近6月(≥3) → 近12月(≥3) | 市场一转冷，预测立刻跟着降；小样本档位自动回退到长期 |

| **FINI 口径隔离** | 2023 年底 FINI 上线后申购资金仅冻结中签额，超购倍数系统性虚高；所有阈值只在 FINI 后样本上重算 | 避免把两个时代的超购数字混在一起比 |
| **实时行情修正** | 恒指与 A 股现价实时抓取 | 当日大盘情绪计入 |
| **实况回测自证** | 每次运行滚动回放最近 ≥12 只已上市新股（**同一算法**） | 防止"拿未来数据美化自己" |

## 八、局限与免责（必读）

- 本预测是**基于历史统计的条件分布推断**，不是荐股、不保收益、不是精确报价器。处置单给的是**执行纪律**（按暗盘实际落点触发），不是收益承诺。
- **方向命中率是真实短板**：实况回测常见 **3~5/12**（模型擅长给区间水平，**不擅长猜单只涨跌方向**）。所以卖出动作全部按**实际落点**触发，而非按预测方向触发。
- 暗盘各券商独立撮合，**价格以你券商 App 为准**；模型统一采用站点收盘口径。
- 免费源拿不到国际配售的认购人结构（长线/对冲占比），这是信息缺口，不是可以硬编的变量。
- 融资打新利息**按日计且不中签也要付**；中签费 1.0085%；**港股通不能参与暗盘**；内地居民境外暗盘盈利按规定需自行申报（20% 个人所得税口径，以最新法规为准）。
- 网络失败或标的不存在时，引擎**明确报错（含 429 限流提示），不编造数字**。

## 九、相对原插件的 16 处方法改进

1. **静态桶 → 实时重算**：写死的 106 只常量 → 每次滚动重算。
2. **分桶改分层窗口**：固定 6 月窗 → 近3月→6月→12月分层（MAE 52.66→46.56）。
3. **删除固定冷热市平移**：因果回测证明为负贡献（MAE 40.05→39.4，中位偏差 −8.4→−5.4）。
4. **S2 从"因子全砍"→ 残差分层修正**：既避免与桶内均值重复计价，又吃到边际信息。
5. **妖股系数 0.7 → 样本标定 ≈1.01**：旧规则已证伪。
6. **保荐人改中位数口径**：原「均值×n 加权」基准 50.7% vs 全样本首日中位 37.4% → 58% 的股票被误判扣分；现改为运行时用站点首日收盘价重建。
7. **剔除 `openPct == 0` 数据污染**：那是抓取缺失值而非真实平开（不剔除会把"破发后熬首日更优"的胜率从 **42% 假造成 70%**）。
8. **S1 的 18C 三重计价 → 单次 +5**。
9. **A+H 两处口径不一致 → 统一 0.238/±12**（文案原写 ±15，已改准）。
10. **FLAT 兜底 +29.7% → 中性 ≈0 宽区间**。
11. **新增「持仓处置单」**：七档卖出规则 + 现金/融资两套 + 盘中形态纪律 + 退出时点排序 + 绿鞋纠偏，全部带样本量依据。
12. **新增「实况回测」+ 限流防护**：滚动自证；`api_get` 加 429 重试退避 + 短 TTL 缓存（实测批量 30 只从 19/30 通过提升到 30/30）。
13. **新增「破发豁免判定」+「三个误区」**：把老板的实战经验用样本逐只验证，量化成可执行规则（判别变量是 A 股锚 × 破发深度，不是绿鞋）；结论为**三态**（适用 / 条件性适用 / 不适用），由本股实际暗盘跌幅驱动。
14. **修派生绿鞋占比绕过 3–30% 防护的 bug**：立讯精密曾算出 **2008.4%**（`greenShares` 抓成 77 亿股，应约 5750 万）。现越界即判定股数本身解析错，**占比与股数一起丢，只保留「有/无」**。
15. **新增「保荐人『不托价』预警」（一票否决）**：老板观察「绿鞋照样崩是操盘方的问题」→ 只看「温和破发 + 有绿鞋」区间（自动控制「托价难度」这个混淆变量），按 `n≥2 且 失败≥2 且 失败率≥50%` 实时生成名单，命中即覆盖 A+H 豁免。报告同时给出 Fisher p 值与样本量。
16. **补齐缺失值哨兵防护，并纠正自己的一次矫枉过正**。第 7 条的过滤只保护了「胜率口径」；本次发现 `dark_pool == 0` 同为哨兵却未过滤，且 `build_sponsor_book()` **完全没做这层防护**。补漏时又改错一次：按「`openPct` 为哨兵」**单信号**过滤，剔掉 46 个条目、把保荐人基准从 **15.2% 虚推到 35.1%（+20pt）**，**静默改变全部预测区间**，且回测 MAE 毫无反应（回测不覆盖保荐人库）。**正解是双信号同时成立才剔**（`openPct` 哨兵 **且** `first_day_close == ipo` 精确相等）→ 基准回到 **15.69%**。⚠️ 两个字段来自**独立数据源**（extras.json 构建期 / 实时 API），单看一个会误剔 14 行真实数据。

## 十一、工程纪律

- `engine.py` 内置 **自检（selfcheck）**：价格 ⇄ 涨跌幅互推、区间方向（lo ≤ hi）、NaN、**步骤端点与最终区间一致性**、样本量下限（<50 报警）、**处置单结构完整性**（七档齐全、每档必带依据、情景必带动作）、**实况回测行完整性**、**市况标签与数字同窗口**。运行时会打印 `[自检通过]` 或告警。
  > 提醒：自检覆盖不到的检查不要写进通过文案（曾出现"打印'处置方案结构正常'但代码里根本没查"的假绿灯，已补实）。
- 报告中的「详细计算式」区块，每个因子都给出**输入 → 公式 → 代入 → 输出**，与引擎代码逐行对应，可核对。
- 报告里的 `FACTORS` / `PLAIN` 是**文档面**，改引擎行为后必须同步改准（历史上多次出现"文档写 A、代码做 B"）。
- 区间严格对应分位标称覆盖率；**宁可用宽区间承认没把握，也不用窄区间假装精确**。
