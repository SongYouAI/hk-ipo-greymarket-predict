# 港股打新 · 暗盘 / 首日开盘预测

> 输入一只中签港股的名称或代码，输出**带区间、带置信、带逐项计算过程**的暗盘收盘价预测（主）与首日开盘价预测（暗盘发生后），并落一份可存档的 HTML 报告。

纯 Python 标准库，**零第三方依赖**，运行时实时联网取数。样本窗口为**最近 12 个月滚动重算**，所以不同时段问同一个代码，会得到随市况刷新的评估。

---

## 一、它预测什么（先把口径说清）

港股打新有三个价格，各券商不互通，很多"预测"就混在这里。本模型只对能建模的两个下手：

| 价格 | 出现时间 | 本模型的态度 |
|---|---|---|
| 暗盘**开盘**价 | T-1 17:00 第一笔 | **不建模**。开盘前几分钟易被大单砸偏、各券商不互通 → 只给「情绪初判」（±5~15pt 情绪带，明确标注非模型输出） |
| 暗盘**收盘**价 | T-1 21:30 | **主预测目标（S2）** —— 信息最全、口径最统一 |
| **首日开盘**价 | T 日 9:30 | **S3 目标** —— 仅当暗盘已发生（有暗盘收盘实测）才有值 |

**诚实边界**：只承诺「方向 + 区间」，不承诺点位。区间越宽 = 这只股在历史样本里越没规律，如实告知，好过假装精确。

- 能访问 `www.i668.vip`、`qt.gtimg.cn`

### 2. 跑一只

```bash

```

参数：

| 参数 | 说明 |
|---|---|
| `"<股票名或代码>"` | 支持代码精确匹配（`03757`）、名称包含（`罗博特科`） |

[S3] 数据不足，无法预测

## 三、三阶段预测与详细计算过程

三个阶段按**时间相位**依次解锁（不是按数据有没有就随便标）：

```
招股截止前 ────────→ S1 招股期      方向性宽区间（无超购数据）
招股截止后→暗盘前 ──→ S2 中签后      暗盘收盘价预测（核心）
暗盘结束后 ────────→ S3 暗盘后      首日开盘价预测
```

### S1 · 招股期预测（信息最少，只给方向）

招股期还没有超购数据，缺了最重要的参考，所以只给**方向性宽区间**，不硬给点位。

**分支 A — A+H 股（有 A 股上市）**

```
中枢 = clamp(0.238 × A股较发行价溢价%, ±12)
区间 = [中枢 − 10, 中枢 + 10]，下沿不低于 −5
```

> A 股现价换算成港币后，相对港股发行价贵得越多，说明港股这边相对"便宜"，上市后向 A 股靠拢的动力越足。斜率 0.238 是回归标定值（**取自 v0.4.5 的 38 只样本**）。注意：**折价深 ≠ 不会破发**，只是平均而言更暖，尾部照样有破发的。

**分支 B — 非 A+H：赛道选档给宽区间**

按股票名称关键词推断赛道系数（站点没有行业字段，只能名称推断，报告里明确标注）：

| 名称命中关键词 | 赛道系数 |
|---|---|
| 科技/电子/半导体/芯片/智能/机器人/精密/光电/光伏/新能源/储能/电池/新材料/医药/生物/医疗… | +8 |
| 消费/食品/饮料/零售/品牌/传媒/文娱/旅游/宠 | +5 |
| 金/矿/资源/铜/锂/钢铁/化工/能源/电力/环保 | −5 |
| 证券/保险/银行/金融 | −2 |
| 未命中 | 0 |

```
系数 > 0  → 区间 [0, +18]
系数 < 0  → 区间 [−15, +5]
系数 = 0  → 区间 [−10, +20]
```

**再叠加两项（两分支共用）**

```
18C 特专科技章节               → 上沿 +5pt（合并单次计入，避免三重计价）
保荐人战绩 = (历史首日均值 − 市场基准) × 0.15, clamp(±8)
基石配售   = (基石占比% − 35%) × 0.12,       clamp(±6)
```

### S2 · 中签后预测（暗盘收盘价，核心）

配售结果公布后，超购倍数到手，这是信息最全的一刻。

**第 1 步 — 超购分档基准（动态重算）**

样本 = 近 12 个月、有超购且有暗盘实测的新股（当前 n≈106）。超购分 7 档：

```
档边界 = [0, 15, 100, 500, 1000, 3000, 6000, ∞)   （倍）
中枢   = median(该档所有样本的暗盘涨幅%)
区间   = [中枢 − dLo, 中枢 + dHi]
         其中 dLo = 中枢 − P25，dHi = P75 − 中枢    ← 不对称，吃右偏尾巴
```

> 为什么用中位数和分位、而不是均值和标准差？因为暗盘涨幅**右偏极严重**（妖股动辄 +100%），均值被右尾拉高，会给出系统性偏高的中枢；用 [P25, P75] 分位区间则天然收敛，且区间宽度有明确含义——它是**真实的 50% 中央区间**（标称覆盖率）。

**第 2 步 — 情绪周期平移（动态校准）**

```
破发率 > 50%  或  中位暗盘涨幅 < 0        → 冷市，中枢 −8pt
破发率 < 30%  且  中位暗盘涨幅 > 10%      → 热市，中枢 +3pt
其余                                       → 中性，0
```

**第 3 步 — 残差分层修正（替代"因子全砍"）**

超购档已经把"热度"吃进去了。还有边际信息的，是**同一热度档内部**的差异：

```
对每个因子取「档位」：
  保荐人：战绩偏离基准 >+3 → pos / <−3 → neg / 其余 mid
  基石  ：占比 >50% → high / <20% → low / 其余 mid
  国配  ：>5倍 → pos / <1倍 → neg / 其余 mid
  赛道  ：系数 >0 → pos / <0 → neg / 其余 mid
  规模  ：募资 <30亿 → pos / >300亿 → neg / 其余 mid

corr = Σ 各因子档位的「样本残差均值」(残差 = 该样本暗盘% − 它所属档中位数)
       每档至少 5 个样本才计入，方向互抵或样本不足则该项不修
corr = clamp(corr, ±10)
中枢 += corr
```

> 为什么是"残差"而不是直接乘权重？因为档中位数里**已经含了均值信息**，再按原始值加权就是重复计价。取残差只保留"同档内部的边际差异"，这才是真增量。

**第 4 步 — 大盘环境（唯一纯实时修正项）**

```
中枢 += 0.3 × 恒指当日涨跌%
```

**第 5 步 — 收敛**

```
中枢 = clamp(中枢, −40%, +400%)
区间 = [中枢 − dLo, 中枢 + dHi]（沿用该档分位半距）
```

**降级路径（超购未录时，绝不给假精确）**

```
有 A+H  → 中枢 = clamp(0.238 × A股溢价%, ±12)，半宽 10/12pt，标「预估」
无 A+H  → 中枢 = 0，半宽 18/22pt（中性兜底，明说"这只我算不准"）
```

> 历史上这里曾是「FLAT 兜底取中位数 +29.7%」——那是右偏样本的误导性数字，已废弃。

### S3 · 暗盘后预测（首日开盘价）

暗盘已收盘，锚点变成实测：

```
暗盘 > +50%   → 中枢 = 暗盘% × ratio，ratio = 样本实测「首日开盘 / 暗盘收盘」中位比，区间半宽 18pt
暗盘 < −5%    → 中枢 = 暗盘% − 2（破发延续），半宽 10pt
其余           → 中枢 = 暗盘%（不调整），半宽 10pt

再加：
  隔夜大盘  → += 0.4 × 恒指涨跌%
  国配 > 5倍 → += 2pt
  保荐人战绩 → (历史首日均值 − 市场基准) × 0.20, clamp(±10)   ← 首日口径
  基石配售   → (基石占比% − 35%) × 0.12,        clamp(±6)
中枢 = clamp(中枢, −45%, +400%)
```

其中 `ratio` 由引擎**每次运行现算**：取所有「暗盘 > 50% 且有首日开盘实测」的样本，`median(首日开盘% / 暗盘收盘%)`，再 `clamp(0.7, 1.3)`，样本不足 5 个退化为 0.7。

> 原插件写死 0.7（"暴跌妖股首日大幅回落"的拍脑袋规则）。41 只样本实测中位比 ≈ **1.01** —— 也就是说，妖股首日开盘**并未系统性收窄**，只是波动放大。已按样本标定。

### 暗盘开盘价 · 情绪初判（辅输出）

```
mid  = (S2 区间上沿 + 下沿) / 2
band = 15pt（S2 中枢 > 50%）/ 8pt（S2 上沿 < 0）/ 5pt（其余）
初判区间 = [mid − band, mid + band]
```

明确标注「非模型输出」：开盘前几分钟大单博弈主导，不可建模。

### 置信星级（由区间宽度定，与涨幅无关）

| 区间宽度 | 星级 |
|---|---|
| ≤ 10pt | ★★★ |
| ≤ 25pt | ★★ |
| > 25pt | ★ |

## 四、因子总表：谁在算分、谁只看、谁拿不到

| 因子 | 状态 | 说明 |
|---|---|---|
| 超购分档 | ✅ 已纳入 | S2 主导项，实时重算中位/分位 |
| A+H 折价锚 | ✅ 已纳入 | S1/S2 统一口径（斜率 0.238、截断 ±12） |
| 残差分层修正 | ✅ 已纳入 | 保荐人/基石/国配/赛道/规模的档位残差均值 |
| 情绪周期平移 | ✅ 已纳入 | 冷市 −8 / 热市 +3 / 中性 0 |
| 大盘环境 | ✅ 已纳入 | 恒指 ×0.3（S2）/ ×0.4（S3） |
| 保荐人战绩 | ✅ 已纳入 | 首日口径标定，故只用于 S1（招股期）与 S3（标的即首日） |
| 基石配售 | ✅ 已纳入 | 招股章程实读占比 |
| 国配超购 | ✅ 已纳入 | S3 直接 +2；S2 经残差分层间接计入 |
| 发行规模 | ✅ 已纳入 | 档位残差均值（**不是**固定加减分） |
| 妖股标定系数 | ✅ 已纳入 | 样本实测 ≈1.01，非拍脑袋常数 |
| 超额配股权（绿鞋） | 👁 只展示 | 港股几乎人人有，区分度低；破发时稳价人可托价，只作提示 |
| 发售结构 | 👁 只展示 | 公开占比/回拨影响中签率与筹码，难折算成单分 |
| 散户中签率 | 👁 只展示 | 与超购高度共线（log-log r ≈ −0.72），单独加入反而添乱 |
| 国配明细（长线占比） | ❌ 拿不到 | 付费数据商内容，免费源不披露 |
| 未上市开盘价 | ❌ 拿不到 | 逻辑上尚未发生，绝不假装能算 |

> **口径对齐纪律**：保荐人战绩与基石占比是按「**首日**」标定的，用在预测「**暗盘**」的 S2 上就是口径错位 —— 这正是它们在消融测试中显得"负增益"的根因。现在这两项只在 S3（标的即首日）直接参与，S2 仅通过残差分层间接计入。

## 五、动态校准：为什么每次运行结果会变

| 机制 | 做法 | 效果 |
|---|---|---|
| **滚动样本窗口** | 只取近 12 个月、有超购 + 有暗盘实测的新股 | 新股上市即入样、老样本自动出窗 |
| **分桶实时重算** | 每次运行重新计算 7 档的中位数与 [P25,P75] | 不依赖写死的常量（原插件写死 106 只，不会随市况更新） |
| **情绪周期平移** | 破发率 / 中位暗盘涨幅判冷热市，整体平移中枢 | 相当于给预测装了温度计 |
| **FINI 口径隔离** | 2023 年底 FINI 上线后申购资金仅冻结中签额，超购倍数系统性虚高；所有阈值只在 FINI 后样本上重算，不跨期混用 | 避免把两个时代的超购数字混在一起比 |
| **实时行情修正** | 恒指与 A 股现价实时抓取 | 当日大盘情绪计入 |

## 七、局限与免责（必读）

- 本预测是**基于历史统计的条件分布推断**，不是荐股、不保收益、不是精确报价器。
- 暗盘各券商不互通，本模型统一采用站点收盘口径。
- 免费源拿不到国际配售的认购人结构（长线/对冲占比），这是信息缺口，不是可以硬编的变量。
- 方向命中有天花板：暗盘层面信息量本身就有限，历史回测方向命中约 76%（样本内）。
- 网络失败或标的不存在时，引擎**明确报错，不编造数字**。

## 八、相对原插件的 7 处方法改进

1. **静态桶 → 实时重算**：写死的 106 只常量 → 每次滚动重算（自带动态校准）。
2. **S2 从"因子全砍"→ 残差分层修正**：既避免与桶内均值重复计价，又吃到边际信息。
3. **妖股系数 0.7 → 样本标定 ≈1.01**：旧规则已证伪。
4. **S1 的 18C 三重计价 → 单次 +5**。
5. **A+H 两处口径不一致 → 统一 0.238/±12**。
6. **FLAT 兜底 +29.7% → 中性 ≈0 宽区间**。
7. **补上情绪周期（冷热市）动态校准**，并标注 FINI 后超购虚高。

## 十、工程纪律

- `engine.py` 内置 **自检（selfcheck）**：价格 ⇄ 涨跌幅互推校验、区间方向检查（lo ≤ hi）、NaN 检查、**步骤端点与最终区间一致性**校验、样本量下限（<50 报警）。运行时会打印 `[自检通过]` 或告警。
- 报告中的「详细计算式」区块，每个因子都给出**输入 → 公式 → 代入 → 输出**，与引擎代码逐行对应，可核对。
- 区间严格对应分位标称覆盖率；**宁可用宽区间承认没把握，也不用窄区间假装精确**。
